# ParaBank Automation Project

Automated test suite for the [ParaBank](http://parabank.parasoft.com/) demo banking web application. This project is designed to demonstrate test automation practices using Selenium WebDriver with Java in Eclipse.

---

## 🔧 Technologies Used

- Java
- Selenium WebDriver
- TestNG (or JUnit)
- Eclipse IDE
- Git
